# GGn Lime STMPE Theme

A standalone CSS-only Gazelle/GGn stylesheet adapted from the PTP-STMPE v2 visual style with restrained lime/neon-green accents.

Use the GitHub Pages stylesheet URL:

```text
https://high-guy-uk.github.io/ggn-lime-stmpe/style.css
```

The theme is written directly against GGn's classic Gazelle selectors and does not import the PTP stylesheet.
